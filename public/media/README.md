Coloque aqui os arquivos gerados a partir dos prompts de imagem/vídeo:

- `bg-loop.mp4` — vídeo de fundo (H.264/mp4, sem áudio, ideal < 5MB para não pesar o carregamento)
- `bg-poster.jpg` — frame estático exibido antes do vídeo carregar (pode ser a própria imagem gerada a partir do prompt de imagem)

Enquanto esses arquivos não existirem, o site continua funcionando normalmente
com os blobs de cor como fundo (ver `.bg-blobs` em `src/index.css`).
